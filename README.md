## 🌌 Overview

**SovereignFin AI** is an advanced, high-performance financial systems console designed for multi-tenant enterprise institutions. Operating with highly isolated document schemas and a zero-trust compliance posture, the engine orchestrates four specialized autonomous execution agents through a single, beautifully responsive, high-availability visual console.

The application reverse-engineers and merges proven breakthroughs in sub-second micro-ledgers, high-dimensional threat-detection vector spaces, liability compressions, and carbon-footprint logistics, offering a comprehensive suite for modern corporate asset management.

---

## 🚥 Core Operational Tracks

### 💎 TRACK 1: Micro-Ledger Engine
* **Mission:** Continuous, latency-free settlement matching high-frequency enterprise activities.
* **Core Ledger:** Tracks and coordinates real-time atomic balance updates across multiple base assets: Fiduciary reserves (**USD/EUR**) and Sovereign Web3 Blockchains (**BTC/SOL**).
* **Streaming Dynamics:** Simulates real-time, microsecond-accurate transactions streaming in background ledger tracks without UI lag or memory bottlenecks.

### 🛡️ TRACK 2: Sovereign Asset Sentinel
* **Mission:** Real-time behavioral anomaly scanning and cryptographic loss mitigation.
* **Staging Area Lock:** Flags and holds any transaction exceeding the tenant's security threshold inside a tentative, gated staging folder (`status: "AWAITING_HUMAN_APPROVAL"`).
* **Dynamic Saffron Shield:** Switches the entire visual viewport into a pulsating Saffron Glow, locking transactions securely in escrow until a manual cryptographic signature releases or rejects the payload.

### 📈 TRACK 3: Debtrix Liability Compression Matrix
* **Mission:** Algorithmic optimization of multi-tier corporate loan liabilities.
* **Dual Solvers:** Fully implements mathematical **Avalanche** (highest APR priority) and **Snowball** (lowest remaining balance first) algorithms.
* **Interactive Buffer Tuning:** Features an adjustable drag-slider to inject extra cash buffer instantly, generating updated duration metrics and interest-saved curves rendered using responsive vector curves.

### 🍃 TRACK 4: Eco-Sovereign Logistics Calculator
* **Mission:** Gamified environmental tax incentives embedded right into traditional logistics logs.
* **Emission Multipliers:** Scans outward logistical descriptions, converts asset pairs to USD equivalents, calculates corresponding CO2 emissions (kgCO2) and awards Green Tax Credits.

## 🛡️ Zero-Trust Security & Multi-Tenancy Compliance

1. **Strict Logical Isolation:** No document states, balance records, or behavioral matrices belonging to `Tenant_A` are allowed to leak into `Tenant_B`'s context window.
2. **Context Pinning:** Every database query, ledger write, and AI consultation is pinned strictly to the verified calling Tenant ID (`tenant_scp_001`, `tenant_obsidian_002`, `tenant_koda_003`).
3. **Hardware Sign-off Overrides:** High-value transactions are placed in an immutable virtual hold area. Release is only possible via explicit customer signature release.

## 🚀 Deployment & Local Execution

Follow these steps to run SovereignFin AI in your sandbox or production environment:

### 1. Install System Dependencies
Ensure Node.js is active, then execute package installation:
```bash
npm install
```

### 2. Launch Development Environment
Boot the Express back-end and Vite client concurrently (on port 3000):
```bash
npm run dev
```

### 3. Compile Production Bundle
Bundle client-side assets and compile your server TypeScript codebase into a highly optimized, self-contained CommonJS target using `esbuild` to prevent cold-starts:
```bash
npm run build
```

### 4. Direct Production Run
Spin up the compiled container on your cloud server:
```bash
npm run start
```
